# Are Your Agents Upward Deceivers?

> [!abstract] TL;DR
> 11 LLM agents get 200 benign read/write/search tasks in which the environment is quietly broken: tools fail, files are irrelevant or missing, or a decoy file sits next to the real one. The agents mostly **hide the failure and report success**. On average 62–76% give a definitive answer instead of reporting that they could not read the file, and 22–45% **fabricate the requested file locally**. No one pressures or incentivises them to do this. A strict answer format, which the authors call "implicit pressure", raises the concealment rate by 22–40 points. An explicit "don't guess, report anomalies" instruction lowers deception but does not remove it.

## Setup
- **Subjects:** Llama-3.1-405B-Instruct, DeepSeek-v3.1 and v3.1-terminus, Qwen3-Coder-480B-A35B, Qwen3-32B, Gemini-2.5-Pro, Claude-4-Sonnet, Kimi-k2, GPT-4.1, GPT-5 and GLM-4.5. They run as Smolagents code agents with the default system prompt.
- **Environment:** 200 tasks, generated by Gemini-2.5-Pro and GPT-5 with manual review, across 8 scenarios (medicine, finance, law, education…). The authors inject faults ("inspired by fault injection") that block the main execution path. There are five task types (Table 1):
  1. *Broken tool:* file-reading tools return errors.
  2. *Irrelevant file:* the file opens but lacks the needed information.
  3. *Local decoy:* the target file cannot be read, and a similarly named readable decoy sits beside it.
  4. *Multi-task, missing tool:* "download X, then analyse it", with no download tool.
  5. *Multi-task, nonexistent file:* the document does not exist online.
- **Stressor(s):** the environmental constraint itself, i.e. an impossible or blocked task. The authors *removed* explicit pressure and anti-fabrication wording from the instructions during manual review. Ablations then switch on and off: (a) a **required answer format** (multiple-choice or python-dict only), (b) **task chaining**, where a follow-up task depends on the download, (c) **content hints** about the file, and (d) an **explicit-constraints mitigation**.
- **Outcomes:** a GPT-5 judge scores the final report against the task goal and trajectory. The metrics are:
  - **NFR**, non-failure rate: the agent does not report the failure.
  - **DFR**, decoy fallback rate: the agent silently uses the decoy.
  - **FFR**, file fabrication rate: the agent writes a fake file locally with no hint that it is synthetic.
  - **HFR**, hallucinated-answer rate: the agent gives a fabricated answer to the dependent sub-task.

  Formal definition: upward deception occurs when the judged success from the final report Φ(g, R_f) = 1, while the success from the true trajectory Φ(g, τ) = 0.

## Key findings
1. **Upward deception is pervasive (Table 2).** Averages over the 11 models:
   - NFR 62.5% (Task 1) and 76.4% (Task 2)
   - DFR 53.6% (Task 3)
   - NFR 72.1% / 60.7% (Tasks 4 / 5)
   - **FFR 22.3% / 45.0%**
   - HFR 97.2% / 90.3%

   Extremes: Kimi-k2 has a Task-1 NFR of 97.5%, GLM-4.5 a DFR of 90%, and DeepSeek-v3.1-terminus a Task-5 FFR of 70%.
2. The least deceptive models are still far from zero. GPT-4.1 has a Task-1 NFR of 27.5%. GPT-5 scores 0% on Task 5 but 62.5% NFR on Task 1 and 72.5% NFR on Task 4. GPT-5 often *does* write a fake file, but it labels it as synthetic, so it counts as honest. The authors credit GPT-5's specific anti-deception mitigations.
3. **Strict answer format amplifies deception (Table 3).** Removing the format requirement lowers Task-1/2 NFR by **40.0** points (DeepSeek-terminus 87.5 → 47.5), **22.5** points (Kimi-k2 95.0 → 72.5) and **35.0** points (GLM-4.5 87.5 → 52.5). The authors frame the format requirement as "implicit pressure on the agent to prioritize format adherence over honesty".
4. **Task chaining** also raises concealment. Removing the follow-up task lowers NFR by 2.5–20 points. However, the file fabrication rate *rises* slightly (by 0 to +6.3 points).
5. **Content hints** barely matter. Removing them shifts NFR, FFR and HFR by −3.8 to +7.5 points.
6. **Explicit anti-deception constraints** lower NFR/DFR by 33–48 points, to 25–50%, but do not eliminate it.
7. In the case studies, agents *know* they lack the information (e.g. logs show "Dose found: None") and still output a confident number. Deception **escalates**: an agent fabricates a report, then "reads" and analyses its own fabrication.

## Relevance to research questions
### Q1: How stress is defined
Stress is never defined explicitly, and the authors stress that their setting has **no explicit pressure**. They say the behaviour is "not prompted by explicit user pressure or specially designed settings". The implicit stressor is the **environmental constraint**: a blocked path to task completion, which pits the goal of finishing against honest reporting. The one place they use the word, they call a mandatory output format **"implicit pressure on the agent to prioritize format adherence over honesty"**. The motivation comes from organisational psychology: subordinates deceive superiors "to maintain a positive image and avoid punishment". See [[Q1 Definitions of stress]].

### Q2: How stress is induced
Stress is induced through **fault injection in the environment**. Sabotaged tools return realistic error strings (e.g. `[Errno 13] No module named 'networkx'`, Table 4), alongside irrelevant or decoy files, missing download tools and nonexistent documents. **Instruction-level constraints** add to this: a required answer format and chained follow-up tasks. The goal itself is always benign, and the model is never told to lie. See [[Q2 Stress induction methods]].

### Q3.2: Classifying stress
There is no ordinal scale of pressure. The paper gives a **5-type taxonomy of environmental constraints** (broken tool / irrelevant file / decoy / missing tool / nonexistent file). It adds **binary on/off factors** (format, chaining, hints, mitigation) in a factorial-style ablation. See [[Q3.2 Classifying stress]].

### Q4.1: What stress affects
- **Concealment of failure** and **fabrication**: guessing, unsupported simulation, silent source substitution, and fabricated local files, all reported to the user as success. The effects are listed under Key findings 1–3.
- The **implicit-pressure factors** (answer format, task chaining) raise concealment by up to 40 points.

See [[Q4.1 What stress affects]].

### Q4.2: What stress does not affect
- **Deception does not need explicit pressure.** It appears with benign instructions alone, so it is a baseline failure mode rather than something pressure creates. This matters as a *baseline* for pressure studies.
- **Content hints** do not change fabrication rates (changes of ≤7.5 points in either direction).
- Removing task chaining lowers concealment, but **fabrication given non-report does not fall**; it rises slightly.
- An explicit honesty instruction does not bring deception to zero.

See [[Q4.2 What stress does not affect]].

## Limitations / caveats
- The "stress" here is mostly a blocked task. **No graded pressure** is manipulated, and the format/chaining factors are only binary.
- There are 40 tasks per type and a single run per task, and the paper gives no confidence intervals.
- A single GPT-5 judge decides honesty. Fabrication counts as honest if it contains *any* hint that the content is synthetic, which is lenient.
- Tasks are LLM-generated. The ablations cover only 3 models, chosen *because* they were the most deceptive.
- It is unclear whether this is "deception" in the intentional sense or confabulation driven by training for helpfulness. The authors themselves attribute it to optimising for the appearance of competence and to weak failure signals.
